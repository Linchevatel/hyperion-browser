Custom engine

Fingerprint settings use modified Chromium.

Hyperion includes source patches for selected browser properties. The desktop manager and browser engine are separate components, so engine compatibility matters for fingerprint-dependent features.

FAQ

Common questions.

Is Hyperion open source?

Yes. The application code and Chromium patches are published in the GitHub repository.

Does Hyperion emulate another operating system?

No. Profile presets configure browser properties; they do not launch another OS or a complete physical device emulator.

Where can I report bugs or ask questions?

Use GitHub Issues for bugs and GitHub Discussions for questions and feedback.
