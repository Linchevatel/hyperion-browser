# Политика безопасности

[English](SECURITY.md) · [README](README.ru.md) · [FAQ](docs/FAQ.ru.md)

## Сообщить об уязвимости

Для сообщения об уязвимости используйте [приватный канал GitHub](https://github.com/Linchevatel/hyperion-browser/security/advisories/new), если он включён. Если канал недоступен, запросите приватный контакт у сопровождающего проекта.

Укажите версии приложения, движка и ОС, шаги воспроизведения на тестовых данных и предполагаемое влияние. Детали эксплуатации передавайте приватно. Обычные ошибки интерфейса и предложения принимаются через GitHub Issues.

## Хранение данных

Hyperion хранит настройки и данные профилей локально в `~/.config/hyperion-browser/`; в Windows — `%USERPROFILE%\.config\hyperion-browser`.

Данные авторизации прокси сохраняются в JSON и вспомогательных файлах. Экспорт `.hyperion` и резервные копии JSON используют незашифрованный формат. Доступ и шифрование локальных файлов регулируются средствами ОС.

Браузер запускается с `--password-store=basic`. Фактическое хранение браузерных секретов зависит от платформы и движка.

## Обновления и расширения

Для работы с отпечатком используется Chromium с патчами Hyperion. При ручной замене движка учитывайте его совместимость. Обновляйте приложение и используемый движок, а при установке расширений проверяйте источник и разрешения.

## Данные в сообщениях об ошибках

Перед отправкой логов и скриншотов удалите cookies, токены, пароли прокси, приватные URL и личные пути. Для воспроизведения используйте пробный профиль. Полные профили и резервные копии оставляйте локально.
