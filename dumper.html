Сбор реального WebGL-фингерпринта для базы пресетов Hyperion

Эта страница извлекает полный аппаратный слепок WebGL на реальной машине в Chrome для пополнения каталога data/webgl_presets/.

  • WebGL 1.0 & WebGL 2.0: Все спецификационные GLenum параметры с сохранением нормативных типов C++ патча (int, uint, float, number, bool, string, *vec).
  • Extensions: Полный канонический список поддерживаемых расширений GPU.
  • Shader Precision: Матрицы точности IEEE-754 для вершинных и фрагментных шейдеров (все 12 комбинаций).
  • Метаданные (_meta): Экран, ядра CPU, RAM, UserAgent, unmasked vendor/renderer и голоса Web Speech API (для генерации hardware kits).
